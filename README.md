## 這個站在做什麼

《楞嚴經》卷五、卷六，二十五位聖者各自說出自己證道的那一道門；卷六末，文殊菩薩受佛之命為娑婆眾生揀選，獨推觀世音菩薩的耳根圓通。

本站以民間手相的通俗說法作為**認識習性的方便與接引**，幫使用者從二十五門中找到最順自己根性的入手處，最後一律導歸文殊菩薩所揀選的耳根圓通。

流程：**取掌相 → 掌相八觀 → 相應圓通（經文＋文殊揀選＋現代修法）→ 同歸耳根**

## 取掌相的兩種方式

| 方式 | 說明 |
|---|---|
| **自己端詳（推薦）** | 八個問題，一問只看一處，恰對掌相八觀。答案直接落在八個維度上，最準確 |
| **拍掌掃描（趣味）** | 鏡頭或上傳照片，於瀏覽器本機以影像梯度概略取相。影像**不上傳、不儲存**；判讀不到手掌時會據實報錯，不硬給結果 |

## 掌相八觀 → 二十五圓通

八個維度：掌形、智慧線、感情線、生命線、事業線、掌丘、紋路密度、指相。

每一門圓通各有一組八維權重（`WEIGHTS`），以 L2 正規化的餘弦相似度取最相應的三門。已窮舉八問的 4⁸ = 65,536 種作答驗證分佈：**二十五門全部可被抽中**，佔比介於 1.1% – 8.4%。

## 資料來源與分際

- **經文原文**（各聖者自陳、文殊菩薩揀選偈）逐字錄自 **CBETA 中華電子佛典協會《大正新脩大藏經》第 19 冊 No. 945**，卷五、卷六，未作改動。資料檔中 `sutra`、`manju` 兩欄即經文。
- **白話說明與修持建議**（`story` / `manjuNote` / `palm` / `practice` / `daily`）為寶嚴禪寺依古德註疏所作的方便語，**非經文**。
- **掌相部分**取民間手相的通俗說法，作為認識自己習性的方便，**不是命理預測，也不涉吉凶禍福**。佛法不許為人卜相以謀利養；此處只借掌紋作一面鏡子，照見習氣、選擇法門。
- 二十五門**實無優劣**——經云「歸元性無二，方便有多門」；文殊菩薩獨選耳根一門，是就娑婆當機而說，不是貶餘二十四門。
