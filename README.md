# 楞嚴二十五圓通．掌紋觀照

《大佛頂首楞嚴經》二十五圓通線上導覽——先端詳自己的掌相八觀，再請出一門圓通作為用功所依。

**線上版**：https://twnyda07.github.io/lengyan-25-yuantong/

---

## 這個站在做什麼

《楞嚴經》卷五、卷六，二十五位聖者各自說出自己證道的那一道門；卷六末，文殊菩薩受佛之命為娑婆眾生揀選，獨推觀世音菩薩的耳根圓通。

站上分作兩件事，**兩者各自獨立**：

1. **掌相八觀** —— 使用者攤開慣用手，**以相機即時拍攝掌心**（不自己填、不上傳照片），程式由影像推估八項掌相。結果只用來**為使用者說明自己手掌的特色與性情之所偏**，不論吉凶，也不用來推算所請之門。影像全程只在本機運算，不上傳、不儲存。
2. **所請之圓通** —— 於二十五門中請出一門，附經文原文、其人其事、文殊揀選偈、三學功課、日用寄語、見輝法師開示，並旁列相關二門。

結尾一律導歸文殊菩薩所揀選的耳根圓通——所請之門是入手處，反聞聞自性是諸門之後的同一條路。

## 抽門的規則：第一次純亂數，同一人重測仍是同門

- **第一次觀照**：以 `crypto.getRandomValues` 取亂數請出一門，對二十五門是均勻隨機的。
  **掌相完全不參與決定是哪一門**——站上對信眾所說的「所請之圓通非由掌相推算而得」因此為實。
- **同一人重測仍得同門**：不是重新算一次算出同樣的答案，而是把第一次請出的門**記下來**
  （本機 localStorage）。掌相只用來認人，不用來決定門。
- **認人的門檻取「相同」而非「相近」**：同一台機器、八觀平均差 ≤ 4、且每一觀各自差距 ≤ 8、
  七日之內，才判為同一人。只容得下同一隻手兩次拍攝的晃動；放寬到「相近」會把下一位
  信眾誤判成同一人而把別人的門給他。
- 不合上述任一條，即視為另一人，**重新以亂數請出新門**。
- 重測時顯示「此為第 N 次觀照。所請之門一經請出，即是君這一段日子用功的所依，故仍是此門」
  ——**據實而說，不宣稱那是巧合之外的印證**（門是記下來的，不是重算出來的）。
- 畫面中認不出足夠的手掌（過暗、手掌太小）時**據實報錯，不硬給結果**。

## 三學功課

每一門各備**教理／福德／禪定**三項功課，三者並行不可偏廢——教理明其所以然，福德厚其資糧，禪定得其受用。

## 資料來源與分際

- **經文原文**（各聖者自陳、文殊菩薩揀選偈）逐字錄自 **CBETA 中華電子佛典協會《大正新脩大藏經》第 19 冊 No. 945**，卷五、卷六，未作改動。資料檔中 `sutra`、`manju` 兩欄即經文。
- **見輝法師開示連結**為《秒懂楞嚴》對應集數（資料檔 `talk` 欄），標題逐字引自 YouTube 官方標題，含原標題之空格與標點，未加修飾。
- **白話說明與三學功課**（`story` / `manjuNote` / `palm` / `practice` / `daily`）為寶嚴禪寺依古德註疏所作之方便語，**非經文**。
- **掌相八觀**取民間手相的通俗說法，僅用於為使用者說明自己手掌的特色，**不是命理預測，也不涉吉凶禍福**；所請之圓通亦非由掌相推算而得。佛法不許為人卜相以謀利養，此處只借掌紋作一面鏡子，照見習氣、依門用功。
- 二十五門**實無優劣**——經云「歸元性無二，方便有多門」；文殊菩薩獨選耳根一門，是就娑婆當機而說，非貶餘二十四門。
